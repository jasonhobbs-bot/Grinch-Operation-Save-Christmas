# Operation Save Christmas — classroom prototype

Open `index.html` in a modern browser. No external libraries, accounts, or server are required.

## Play
Choose Pre-K through grade 5, a character, and a mode. Quick Play rotates randomized missions, with a configurable 10-minute default. Story Adventure has 12 chapters. Exploration, sleigh racing and workshop are repeatable modes.

- Keyboard: WASD or arrows, Space to jump, E to interact, Escape to pause.
- Touch: on-screen joystick, Jump and Action.
- Teacher settings: session length, music, sound effects, speech, navigation assistance, automatic return to menu.
- Local storage saves settings, best score and optional story progress on the device. No student data is transmitted.

## Status
This is a 2.5D canvas prototype with original procedural graphics and synthesized sound, not a full 3D open world. JavaScript syntax and mocked DOM startup/mission smoke tests passed; real iPad and Chromebook playtesting remains necessary. No official artwork, recordings, or book text included. Unofficial educational companion; review rights and permissions before public deployment. No affiliation with the rights holders.

## Deployment
After reviewing permissions, enable GitHub Pages from the repository Settings > Pages, select Deploy from a branch, main, /(root), and Save. The game can also be tested privately by downloading the HTML and opening it locally.
